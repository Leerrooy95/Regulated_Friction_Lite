# The Regulated Friction Project — Lite v1.0

A short version of [The_Regulated_Friction_Project](https://github.com/Leerrooy95/The_Regulated_Friction_Project), built so the whole project fits in one AI context window. It's seven files. Everything else stays in the main repo, and this repo links to it instead of copying it.

---

## What the research found

Several groups are moving the same direction at once: federal restructuring, private tech executives stepping into public advisory roles, state governments trading public checks for corporate investment, and party discipline for anyone in the majority who breaks ranks. Each change was a deliberate choice by someone, but the groups don't need to be coordinating with each other. What changed is that the things that used to slow them down were removed, one at a time, mostly in public.

The timing research backs this up. Friction events (scandals, releases, media cycles) come before compliance events (policy moves, deals, appointments) with a **7-day median lag, r = +0.6196, p = 0.0004** (the analysis that produced these results was done December 2025 with limited data, it's likely much more consistent). Once the other checks are gone, public attention is the main thing left that can slow anything down, and the data shows things move when attention is elsewhere.

This is about correlation and structure. It doesn't claim causation, central coordination, or illegal activity.

## Using this with an AI

For most conversations, give it `The_Structure.md`, `Core_Theory.md`, and `AI_Context_Index.md`. Add `Corrections_and_Caveats.md` if it's going to cite specific figures, and `Baseline_and_Learnings.md` if you want it to understand how you read the research.

A good opening line: *"This is my research project's context pack. Treat ✅ as verified, ⚠️ as partial, 🔍 as hypothesis, and don't upgrade certainty. Check Corrections_and_Caveats.md before quoting numbers. If you need detail, ask me or follow the main-repo links."*

## Adding new material

The main repo is the system of record. New research goes there first. Lite only changes when a finding is solid enough to matter:

- **A new topic** gets one entry in `AI_Context_Index.md` (a few lines plus main-repo links), not a new file.
- **A finding that changes the big picture** gets a line or section in `The_Structure.md`.
- **A correction or new contradiction** goes in `Corrections_and_Caveats.md`.
- **A new prediction or result** goes in `Predictions_Tested.md`.
- **A new file** only when it's a new kind of thing, not just a new topic.

Coming later, once sourced in the main repo: a Project 2025 proposal-to-action mapping and Detachment 201 (see `The_Structure.md` §8), and the `16_MISINFORMATION_ANALYSIS/` track, which is still in progress.

## Disclaimer

Everything here comes from publicly available data. The claim is structural: the patterns exist, they're statistically significant, and they can be reproduced. It makes no claims about anyone's intent, individual motives, or guilt, or about whether the separate groups coordinate. Anyone can reproduce the core correlation with the main repo's [`Run_Correlations_Yourself/`](https://github.com/Leerrooy95/The_Regulated_Friction_Project/tree/main/Run_Correlations_Yourself).
